# Rima Fathallah - Premium Portfolio Website

A world-class, production-ready personal portfolio website featuring AI Engineer, Researcher, and Data Science Innovator **Rima Fathallah**.

## 🌟 Features

- **Modern, Cinematic Design** - Inspired by Apple, Tesla, Linear, Stripe, and Vercel
- **Advanced 3D Visualizations** - Neural networks and particle systems using React Three Fiber
- **Smooth Animations** - Framer Motion and GSAP for cinematic transitions
- **Fully Responsive** - Mobile-first design that works on all devices
- **Performance Optimized** - Code splitting, lazy loading, and optimized assets
- **SEO Ready** - Meta tags, semantic HTML, and accessibility features
- **Dark/Light Mode** - Premium visual theme with customizable colors

## 🎨 Design Vision

The portfolio showcases:

- **Hero Section** - Full-screen immersive introduction with 3D neural networks
- **About** - Journey timeline from mathematics to AI innovation
- **Research** - MITACS research internship highlights with visualization pipeline
- **Projects** - Featured projects including DEXTRA, NEXOVA, Talynk
- **Skills** - Interactive skills ecosystem across multiple categories
- **Experience** - Animated vertical timeline of career journey
- **Leadership** - Global impact and IEEE initiatives
- **Certifications** - Industry-recognized credentials with floating badges
- **Awards** - Recognition and achievements showcase
- **Contact** - Premium contact experience with form and social links

## 📦 Installation

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Setup Steps

```bash
# Clone the repository
git clone <repository-url>
cd "Rima Fathallah - Pt26"

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Getting Started

### Development
```bash
npm run dev
```
The development server will start at `http://localhost:3000` with hot module replacement enabled.

### Production Build
```bash
npm run build
```
This creates an optimized production build in the `dist/` directory.

### Type Checking
```bash
npm run type-check
```
Run TypeScript compiler to check for type errors.

### Linting
```bash
npm run lint
```
Run ESLint to check code quality.
